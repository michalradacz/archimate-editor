# English: Web ArchiMate 3.2 editor

Online version at https://egdilna.github.io/nastroje/archimate

You can download single HTML file at this repository to work at your infrastructure.


Supports AJX (ArchiMate JSON Exchange) and Archimate XML (AEX) formats


ℹ️ Many informations are in [detailed user guide](archimate-editor-docs-en.md) - and I am too lazy to detail working on readme.

This is only accessible ArchiMate 3.2 architecture model editor. Works locally in browser as single-file-application, using only standard UI elements of HTML and its 100% accessible for screenreaders, with accessible SVG export too. It implements full ArchiMate 3.2 standard, specialization (as stereotypes for elements), tags, filtering, customizing table display, etc.

It supports full architecture model creation and management for blind people, with designing diagrams too.

It contains full web frawing editor for detailed diagram design too.

# Česky: Webový editor ArchiMate 3.2

Online verze na https://egdilna.github.io/nastroje/archimate

Můžete si stáhnout jeden HTML soubor z tohoto repozitáře a provozovat editor na vlastní infrastruktuře.

Podporuje formáty AJX (ArchiMate JSON Exchange) a ArchiMate XML (AEX).

ℹ️ Mnoho informací najdete v [podrobné uživatelské příručce](archimate-editor-docs-cs.md) – a jsem příliš líný na to, abych vše popisoval v readme.

Toto je jediný plně přístupný editor architektonických modelů ArchiMate 3.2. Funguje lokálně v prohlížeči jako jednosouborová aplikace, používá pouze standardní UI prvky HTML a je 100% přístupný pro odečítače obrazovky, včetně přístupného exportu do SVG. Implementuje kompletní standard ArchiMate 3.2, specializaci (jako stereotypy prvků), příznaky, filtrování, přizpůsobení zobrazení tabulek atd.

Umožňuje nevidomým uživatelům kompletní tvorbu a správu architektonických modelů, včetně návrhu diagramů.

Obsahuje i vizuální editor pro detailní designování diagramů.
